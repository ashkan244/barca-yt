## ۲. استانداردهای زمان‌بندی (پلتفرم یوتیوب)

- **قلاب ۰ تا ۱۵ ثانیه:** بدون لوگو و موزیک اینترو. اولین تصویر پرحرکت است و جمله‌ی اول یا ادعا است یا سؤال.
- **وعده تا ثانیه‌ی ۴۵:** بیننده بداند در پایان چه چیزی دستش را می‌گیرد.
- **فصل‌ها (Chapters):**
  - اولی ۰:۰۰، حداقل ۳ فصل، هر فصل ≥۱۰ ثانیه
  - عنوان فصل‌ها هم کنجکاوی‌برانگیز باشد و هم قابل جستجو
- **تغییر الگو هر ۲۰ تا ۴۰ ثانیه:** زاویه‌ی دوربین تخته، زوم، گرافیک تازه یا کارت متن. هیچ نمای ثابتی بیشتر از ۸ ثانیه نمی‌ماند.
- **تبلیغ وسط ویدیو (ویدیوهای ۸ دقیقه به بالا):** فقط روی مرز فصل‌ها، بعد از یک «تعلیق کوچک»، حدود هر ۴ تا ۶ دقیقه. محل هر تبلیغ در هر اسکریپت با `⏸ MID-ROLL` مشخص شده.
- **سرعت روایت:** ۱۴۵ تا ۱۵۵ کلمه در دقیقه (Kokoro با speed 1.0 حدود ۱۵۰ کلمه).
  - **فرمول:** طول هدف × ۱۵۰ = تعداد کلمات روایت (منهای زمان‌های بی‌کلام: مکث، موزیک، افکت).
- **تنفس:** ۱ تا ۳ ثانیه سکوت بعد از هر جمله‌ی کلیدی (`[pause 1.5]`).
- **پایان:** ۲۰ ثانیه‌ی آخر صفحه‌ی پایانی (End Screen) با ۲ کارت ویدیو و دکمه‌ی اشتراک. روایت در ۱۵ ثانیه‌ی آخر به ویدیوی بعدی اشاره می‌کند.

## ۴. صدا

- **راوی:** Kokoro با صدای `am_michael`، speed 1.0 (فعلاً محلی؛ بعداً ElevenLabs با همین متن‌ها).
- **موزیک:** بستر آرام زیر روایت، ۲۰ دسی‌بل پایین‌تر، با کاهش خودکار حجم هنگام صحبت. یک تم ثابت برای کانال و یک تم برای هر فرمت. منبع موزیک در گام بعدی انتخاب و لایسنسش ثبت می‌شود.
- **افکت:** کشیدن گچ (ظاهر شدن فلش)، whoosh (کات)، تیک ساعت (شمارش)، جمعیت دور (لحظه‌ی گل). فقط CC0 یا لایسنس ثبت‌شده.
- **بلندی:** −14 LUFS برای کل ویدیو، پیک −1 dBTP.

## ۵. نشانه‌گذاری اسکریپت (برای ساخت خودکار صدا)

هر جمله‌ی روایت در فایل قسمت این شکل را دارد:

```
> [PL-012] Most midfielders look at the ball. Pedri looks at everything else first.
```

- `PL-012` شناسه‌ی یکتای خط است. فایل صوتی همان شناسه را می‌گیرد: `studio/public/audio/PL/PL-012.wav`.
- `[pause 1.5]` در انتهای خط یعنی ۱.۵ ثانیه سکوت بعد از آن خط.
- `[speed 0.95]` در ابتدای خط یعنی سرعت آن خط.
- `[VERIFY]` در فکت‌شیت یعنی آن حقیقت باید قبل از ضبط نهایی دوباره چک شود.

## ۶. دستور ساخت (برای همه‌ی قسمت‌ها)

```bash
# 1) استخراج خطوط روایت از اسکریپت → JSON
node tools/tts/extract.mjs episodes/01-PL-pedri.md > tools/tts/PL.json

# 2) تولید صدا (محلی، Kokoro) → studio/public/audio/PL/*.wav + durations.json
cd tools/tts && node say.mjs PL.json ../../studio/public/audio/PL

# 3) کد صحنه‌ها: studio/src/episodes/PL/*.tsx  (تایم‌لاین از durations.json ساخته می‌شود)
# 4) پیش‌نمایش و تک‌فریم محلی
cd studio && npx remotion still src/index.ts EP-PL out/check/PL_0900.jpg --frame=900

# 5) همگام‌سازی با مخزن عمومی و رندر ابری (۸ تا ۱۲ جوین موازی برای ویدیوی بلند)
bash tools/sync-render-repo.sh && cd ../barca-yt-render && git add -A && git commit -m "EP-PL" && git push
gh workflow run render.yml -f composition=EP-PL -f chunks=10 -f crf=20

# 6) دانلود خروجی
gh run download <run-id> -R ashkan244/barca-yt-render -n EP-PL -D studio/out/cloud
```

**برآورد رندر ابری** (۷ فریم بر ثانیه برای هر جوین، اندازه‌گیری‌شده): ویدیوی ۱۰ دقیقه‌ای با ۱۰ جوین حدود ۵ دقیقه، و FS سی‌ودودقیقه‌ای با ۱۲ جوین حدود ۱۵ دقیقه.
